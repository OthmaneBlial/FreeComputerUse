# Implementation contract

The original brief is implemented in eight milestones, with runnable checks at
each boundary. FreeComputerUse is the existing workspace name.

1. TypeScript / Playwright runtime, semantic DOM references, ranked selectors,
   forms, frames, shadow DOM, bounded compression and action DSL.
2. Abstract provider, Flash-compatible HTTP integration, structured plan batches,
   local profile placeholders and prompt trust boundaries.
3. Deterministic conditions, execution receipts, bounded repair and control gates.
4. DOM diffs, state hashes, loop limits, token reservations and honest cost metrics.
5. Private SQLite traces, semantic learned workflows and zero-provider replay.
6. CLI run/open/inspect/replay/workflows/history/config/doctor, interactive control.
7. Local three-column dashboard, live browser preview, task and human control.
8. Real local fixture website, six reproducible scenarios, job demo and documentation.

No API key is present. Fixture-provider tests prove runtime and protocol behavior,
not any commercial model's task understanding. External model performance must be
validated with credentials. General site adapters, multi-model routing and robust
visual-only execution are extensible future work, not claimed integrations.

Security invariants: no model-generated code execution, strict action schemas,
page content is untrusted, profile values resolve locally, uploads are limited to
explicit local file aliases, network destinations are constrained by a local
policy, irreversible operations require configurable human approval. Local traces
can contain extracted website data and must be treated as private.
