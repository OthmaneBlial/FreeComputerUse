# FreeComputerUse 0.2.5

The planner no longer has to repeat the task goal it already received as trusted
context. The runtime keeps and validates the original goal, so long or non-English
tasks leave more response budget for actionable steps, browser actions and checks.
The existing 4,000-character task-goal limit still applies.

## Install

Requires Node.js 22.13+, npm and an installed browser.

```bash
npm install --global free-computer-use@0.2.5
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Common page-reading and link-extraction tasks work
without a model key; open-ended tasks need a configured provider. See the
[README](https://github.com/OthmaneBlial/FreeComputerUse#quick-start) and
[support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/main/docs/SUPPORT_MATRIX.md).

## Local validation

`FCU_BROWSER_CHANNEL=chrome npm run validate` passed 138/138 tests in 177.90
seconds, followed by build, security scan and npm audit with zero
vulnerabilities. Environment: macOS 26.6 on Apple Silicon, Node.js 25.9.0,
npm 11.12.1 and system Chrome 154.0.8037.57. No live model-provider request
was made.
