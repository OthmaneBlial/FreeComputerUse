# FreeComputerUse 0.2.11

Damaged or incompatible learned workflows no longer stop a task or replay a
different cache record. FreeComputerUse skips an invalid cache entry and lets
the planner continue.

## Install

Requires Node.js 22.13+, npm and an installed browser.

```bash
npm install --global free-computer-use@0.2.11
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

If npm has not finished serving the package, download
[`free-computer-use-0.2.11.tgz`](https://github.com/OthmaneBlial/FreeComputerUse/releases/download/v0.2.11/free-computer-use-0.2.11.tgz)
from this release and install it with:

```bash
npm install --global ./free-computer-use-0.2.11.tgz
```

Open `http://127.0.0.1:4318`. Common page-reading and link-extraction tasks work
without a model key; open-ended tasks need a configured provider. See the
[README](https://github.com/OthmaneBlial/FreeComputerUse#quick-start) and
[support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/main/docs/SUPPORT_MATRIX.md).
