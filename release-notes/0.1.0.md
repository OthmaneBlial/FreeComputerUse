FreeComputerUse is a local-first browser automation agent. A configured model
plans bounded actions; Playwright performs browser work locally; the agent
checks whether the requested result was reached.

## Included

- CLI, TypeScript library entry point, and a loopback-only local dashboard.
- DOM-first page observation and bounded, schema-validated browser actions.
- Per-origin website approval, separate confirmation for sensitive actions,
  pause/stop controls, and result checks.
- Local run history and compatible semantic workflow replay. A replayed
  workflow can avoid another model call when the page still matches.
- API routes for OpenAI-compatible endpoints and Anthropic Messages, plus local
  Codex CLI and Claude Code subscription routes. Subscription routes use the
  installed CLI and do not bypass account or plan limits.
- A synthetic practice lab and a model-free `Extract the table` workflow.

## Compatibility limits

- Verified target: macOS 26.6 on Apple Silicon, Node 25.9.0, and system Chrome
  154.0.8037.57. The declared Node floor of 22.13.0, other operating systems,
  browser builds, and standalone binaries are not verified.
- One synthetic DeepSeek Flash completion and one synthetic plan through Codex
  CLI 0.156.1 with a ChatGPT login have live evidence. The ChatGPT check did not
  run a browser task. OpenAI, xAI/Grok, Gemini, Mistral, OpenRouter, and
  Anthropic API routes remain unverified against their live services.
- The installed Claude Code CLI failed its local version command; the project
  requires Claude Code 2.1.248 or newer before attempting that route.
- Run history, profiles, workflows, and downloads stay on disk but are not
  encrypted and do not expire automatically. Selected task and page context
  goes to the configured model provider; screenshots are not sent.
