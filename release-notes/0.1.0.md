# FreeComputerUse 0.1.0

Published on npm on 24 September 2026. This release provides a local-first browser agent with a reviewed, checksum-verified npm package.

## Included

- CLI, TypeScript library entry point, and loopback-only dashboard.
- DOM-first page observation, bounded schema-validated actions, per-origin approval, sensitive-action confirmation, pause/stop controls, and result checks.
- Local run history and compatible workflow replay, which can avoid another model call when the page still matches.
- OpenAI-compatible and Anthropic API routes, plus local Codex CLI and Claude Code subscription routes. Subscription routes use installed CLIs and do not bypass account or plan limits.
- A synthetic practice lab with a deterministic `Extract the table` task that needs no provider key.
- A local MCP server over `stdio` with four bounded tools and human-controlled approval.

## Install

Requires Node.js and an installed browser. The verified target is macOS 26.6 on Apple Silicon, Node 25.9.0, and system Chrome 154.0.8037.57. Other operating systems, the declared Node floor, and other browser builds remain unverified.

```sh
npm install --global free-computer-use@0.1.0
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. The synthetic practice task works without a model key. Configure a supported provider for general model-planned tasks; API billing and consumer subscriptions are separate products.

No standalone executable or bundled browser is included.

## Provider and accessibility limits

- One synthetic DeepSeek Flash completion and one synthetic plan through Codex CLI 0.156.1 with a ChatGPT login have live evidence. The ChatGPT check did not run a browser task. OpenAI, xAI/Grok, Gemini, Mistral, OpenRouter, and Anthropic API routes remain unverified against their live services.
- The installed Claude Code CLI failed its local version command; use Claude Code 2.1.248 or newer before attempting that route.
- Keyboard navigation, accessible names, responsive behavior, and contrast checks were verified in browser automation. Spoken VoiceOver/NVDA output was skipped at the user's request and is unverified; no screen-reader compatibility claim is made.
- Run history, profiles, workflows, and downloads remain on disk, are not encrypted, and do not expire automatically. Selected task and page context goes to the configured model provider; screenshots are not sent.
