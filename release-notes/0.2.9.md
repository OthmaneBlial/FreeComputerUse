# FreeComputerUse 0.2.9

Independent completion checks now run concurrently. When an action repeats at
the same observed page state, the agent asks its provider for one bounded
repair; it stops if the repaired plan repeats the same action again.

The regression tests verify both recovery and the loop stop. The historical
live GitHub audit failure was not rerun with a model provider, so this release
does not claim that the full audit task now succeeds.

## Install

Requires Node.js 22.13+, npm and an installed browser.

```bash
npm install --global free-computer-use@0.2.9
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Common page-reading and link-extraction tasks work
without a model key; open-ended tasks need a configured provider. See the
[README](https://github.com/OthmaneBlial/FreeComputerUse#quick-start) and
[support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/main/docs/SUPPORT_MATRIX.md).
