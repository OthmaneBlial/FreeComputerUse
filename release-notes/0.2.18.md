# FreeComputerUse 0.2.18

Page observation and repair context now agree on what is visible. Visible descendants that override hidden ancestor styles remain available, while collapsed content and blocked background text stay out of repair snippets. Targeted repair context now also includes visible content from open shadow roots and keeps hidden and sensitive values filtered.

## Install

Requires Node.js 22.13+, npm, and an installed browser.

```bash
npm install --global free-computer-use@0.2.18
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Read the [README](https://github.com/OthmaneBlial/FreeComputerUse#quick-start) and [support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/main/docs/SUPPORT_MATRIX.md) for setup and current limits.
