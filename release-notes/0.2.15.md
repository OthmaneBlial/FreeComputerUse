# FreeComputerUse 0.2.15

This patch closes sensitive-action and hidden-content gaps across open Shadow
DOM roots.

## What changed

- Resolve shadow-root `aria-labelledby` labels when classifying sensitive
  fields, and recheck those labels after approval before entering text.
- Redact labeled payment values in record extraction.
- Exclude hidden, inert and blocked-modal content from text, table, link, record
  and repair-context extraction across open shadow roots.

## Install

Requires Node.js 22.13+, npm, and an installed browser.

```bash
npm install --global free-computer-use@0.2.15
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Common page-reading and link-extraction tasks work
without a model key; open-ended tasks need a configured provider. See the
[README](https://github.com/OthmaneBlial/FreeComputerUse#quick-start) and
[support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/main/docs/SUPPORT_MATRIX.md).
