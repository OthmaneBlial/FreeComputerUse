# FreeComputerUse 0.2.22

This release improves cached browser workflow replay, task traces, and
dashboard request validation.

## What's new

- Wait up to 1.5 seconds for a known single-page-app workflow to hydrate before
  falling back to model planning.
- Record whether each browser action changed the observed page state.
- Reject malformed UTF-8 in dashboard JSON requests while preserving valid
  Unicode split across network chunks.
- Return immediately after a failed zero-timeout verification check.

## Install

Requires Node.js 22.13+, npm, and an installed browser.

```bash
npm install --global free-computer-use@0.2.22
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. No provider key is needed for built-in reading,
link extraction, or the synthetic practice table.
