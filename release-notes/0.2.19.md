# FreeComputerUse 0.2.19

A broken event subscriber can no longer fail a browser task or block other listeners. Event delivery remains isolated from local page execution.

## Install

Requires Node.js 22.13+, npm, and an installed browser.

```bash
npm install --global free-computer-use@0.2.19
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Read the [README](https://github.com/OthmaneBlial/FreeComputerUse#quick-start) and [support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/main/docs/SUPPORT_MATRIX.md) for setup and current limits.
