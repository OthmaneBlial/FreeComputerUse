# FreeComputerUse 0.2.2

Released 26 September 2026.

## Planner context

- Keep the page snapshot, recent open tabs and prior extraction evidence inside
  one character budget. Long tasks no longer append an unbounded evidence list
  to every planner request.
- Include bounded previews for up to eight recent extractions, preserving the
  newest results first. Structured previews limit strings, arrays and object
  fields before serialization.
- Redact sensitive values before enforcing the final page-context cap.

## Install

Requires Node.js 22.13+, npm and an installed browser. The verified setup uses
macOS 26.6 on Apple Silicon, Node 25.9.0 and system Chrome 154.0.8037.57.
Other operating systems, Node versions and browser builds remain unverified.

```sh
npm install --global free-computer-use@0.2.2
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Page-text, link and synthetic table tasks work
without provider credentials. Configure a supported model route for open-ended
tasks. Browser execution, profiles, history and downloads stay local; local data
is not encrypted and does not expire automatically.
