# FreeComputerUse 0.2.4

Released 27 September 2026.

## Consistent task-goal limit

CLI and direct library users now follow the same 4,000-character goal limit as
the dashboard and MCP. Overlong goals are rejected before browser startup or
trace creation, instead of failing later when the planner validates its output.

## Install

Requires Node.js 22.13+, npm and an installed browser. The validated setup uses
macOS 26.6 on Apple Silicon, Node 25.9.0 and system Chrome 154.0.8037.57.
Other operating systems, Node versions and browser builds remain unverified.

```sh
npm install --global free-computer-use@0.2.4
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Page-text, link and synthetic table tasks work
without provider credentials. Configure a supported model route for open-ended
tasks. Browser execution, profiles, history and downloads stay local; local data
is not encrypted and does not expire automatically.
