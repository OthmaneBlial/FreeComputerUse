# FreeComputerUse 0.2.17

DOM size and compression metrics now include markup inside open shadow roots. This keeps the reported page size aligned with the content the agent can actually inspect, including nested roots and multibyte UTF-8 text.

## Install

Requires Node.js 22.13+, npm, and an installed browser.

```bash
npm install --global free-computer-use@0.2.17
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Common page-reading and link-extraction tasks run locally without a model key; open-ended tasks use the provider you configure. Read the [README](https://github.com/OthmaneBlial/FreeComputerUse#quick-start) and [support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/main/docs/SUPPORT_MATRIX.md).
