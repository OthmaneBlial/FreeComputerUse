# FreeComputerUse 0.2.1

Released 26 September 2026.

## Security and reliability

- Redacts recognized GitHub, GitLab and Slack access-token formats from model
  prompts, traces and history output. The filters cover documented provider
  prefixes ([GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-authentication-to-github), [GitLab](https://docs.gitlab.com/security/tokens/), [Slack](https://docs.slack.dev/authentication/tokens/)); they cannot find every secret in arbitrary page content.
- Drops HTTP proxy requests canceled during DNS lookup and cancels active
  upstream HTTP work when the browser disconnects.
- “First/top N links” requests now return the available count when a page has
  fewer links than requested.
- Retries one bodyless GET or HEAD after a reused-socket reset. Requests that
  could cause side effects are never replayed.

## Install

Requires Node.js 22.13+, npm and an installed browser. The verified setup uses
macOS 26.6 on Apple Silicon, Node 25.9.0, and system Chrome 154.0.8037.57.
Other operating systems, Node versions and browser builds remain unverified.

```sh
npm install --global free-computer-use@0.2.1
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. Page-text, link and synthetic table tasks work
without provider credentials. Configure a supported model route for open-ended
tasks. Browser execution, profiles, history and downloads stay local; local data
is not encrypted and does not expire automatically.
