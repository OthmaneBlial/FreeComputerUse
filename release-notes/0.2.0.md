# FreeComputerUse 0.2.0

Released 26 September 2026.

## Try page reading without a model key

Version 0.2.0 adds deterministic local strategies for common, fully specified
page-reading tasks:

- `Read the page` extracts visible page text.
- `Extract the links` lists visible link labels and URLs.
- `Extract the first 5 links` extracts a bounded number of links and verifies
  the exact requested count. Limits from 1 through 1,000 are supported.
- The synthetic revenue-table task remains available without a provider.

These strategies make zero model calls. They do not make arbitrary browser tasks
model-free; open-ended goals still need a configured provider.

## Reliability improvements

- Element conditions now check every matching element, so a later matching
  element can satisfy verification.
- A selector check with a zero-millisecond timeout returns immediately instead
  of sleeping through a polling interval.

## Install

Requires Node.js 22.13+, npm and an installed browser. The verified setup uses
macOS 26.6 on Apple Silicon, Node 25.9.0, and system Chrome 154.0.8037.57.
Other operating systems, the declared Node minimum and other browser builds
remain unverified.

```sh
npm install --global free-computer-use@0.2.0
FCU_BROWSER_CHANNEL=chrome agent doctor
FCU_BROWSER_CHANNEL=chrome agent ui
```

Open `http://127.0.0.1:4318`. The page-text, link and synthetic table tasks work
without provider credentials. Configure a supported model route for open-ended
tasks. API billing and consumer subscriptions are separate products.

## Privacy and provider limits

Browser execution, profiles, history and downloads stay on the local machine.
The selected task and page context are sent to the configured provider for
model-planned tasks; screenshots are not sent. Local data is not encrypted and
does not expire automatically. Review [security boundaries](https://github.com/OthmaneBlial/FreeComputerUse/blob/v0.2.0/SECURITY.md),
[local data handling](https://github.com/OthmaneBlial/FreeComputerUse/blob/v0.2.0/docs/LOCAL_DATA.md) and the dated
[support matrix](https://github.com/OthmaneBlial/FreeComputerUse/blob/v0.2.0/docs/SUPPORT_MATRIX.md). Provider contract tests do not
certify a live provider.
